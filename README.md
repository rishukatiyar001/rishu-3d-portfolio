## 🌟 Key Features

- **10 Interactive 3D Worlds**:
  1. **Workstation World**: Central developer battle-station with ergonomic gaming chair, cyber hoodie insignia (`</> RISHU KATIYAR`), pro studio RGB headset, typing character, and multi-monitor setup.
  2. **Full Stack Architecture World**: Interactive 6-tier pipeline (Angular &rarr; ASP.NET Core &rarr; Business Logic &rarr; Dapper ORM &rarr; SQL Server &rarr; Azure) with animated request/response particles and clickable deep-dive modals.
  3. **ERP & Smart Meter Billing City**: Living digital city representing smart electric meter telemetry ingest, automated tariff calculations, and customer recharge portals.
  4. **ICICI Fintech Cryptographic Tunnel**: Hexagonal encrypted payment tunnel showcasing HMAC SHA-256 signature workflows, idempotent webhook handling, and mobile deep linking.
  5. **Cross-Platform Mobile Ecosystem**: 3D smartphone simulator highlighting Ionic & Capacitor native features (camera scanning, offline SQLite caching, Firebase alerts).
  6. **Cloud & DevOps Citadel**: Telemetry monitors for Docker containerization, GitHub Actions CI/CD pipelines, and Azure App Services.
  7. **Project Constellation**: 9 production-verified engineering systems with category filtering and live/GitHub links.
  8. **Skills Constellation**: Curated technology matrix spanning Frontend, Backend, Database, Mobile, Cloud, and 3D Creative Engineering.
  9. **Experience Timeline Rail**: Chronological timeline of enterprise engineering delivery.
  10. **Communications Gateway**: Direct contact form terminal and social integration channels.

- **Executive Recruiter Mode (30-Second Fast Scan)**:
  - Instant access to candidate summary, verified production deliverables, core stack pills, and 1-click email/LinkedIn actions.

- **Developer CLI Terminal**:
  - Built-in interactive command line interface (`help`, `stack`, `projects`, `contact`, `whoami`, `clear`).

- **Responsive Mobile Holo-HUD & Adaptive 3D Camera**:
  - Dynamically adapts camera field of view (FOV) and distance on portrait phones so that 100% of the 3D structures and node diagrams are visible without clipping.
  - Dedicated mobile bottom dock chip with slide-up world selection sheet and buttery-smooth touch swipe navigation.
  - Automatic widescreen desktop mode on landscape device rotation.

## 🛠️ Technology Stack

- **Frontend & UI**: Angular 21, TypeScript, Vanilla SCSS Design Tokens, Standalone Components, Signals
- **3D Graphics & Motion**: Three.js (r182), GSAP (GreenSock) for cinematic camera choreographies and easing
- **Backend & Cloud Architecture Represented**: ASP.NET Core Web API, C#, SQL Server, Dapper Micro-ORM, Microsoft Azure, Docker, GitHub Actions CI/CD
- **Mobile Stack**: Ionic, Capacitor (Android & iOS)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v20+ recommended)
- [npm](https://www.npmjs.com/)

### Installation

```bash
git clone https://github.com/rishukatiyar001/rishu-3d-portfolio.git
cd rishu-3d-portfolio
npm install
```

### Development Server

Run the local development server:

```bash
npm start
# or: npx ng serve
```

Navigate to `http://localhost:4200/` (or specified dev port). The app automatically reloads when source files are modified.

### Production Build

```bash
npm run build
```

Compiled production artifacts and prerendered routes are output to the `dist/` directory.
